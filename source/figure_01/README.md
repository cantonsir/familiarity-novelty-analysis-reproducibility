# Main Figure 1 source

`main_figure_01_editable.pptx` is the editable authoring file for Main Figure 1.
The publication-ready page is stored at
`outputs/figures/main/main_figure_01.pdf`.

Figure 1 is a conceptual overview of the task sequence, visual-stimulus
categories, and questionnaires. It does not contain a statistical analysis and
therefore has no preprocessed-data input or Python plotting script.

The PowerPoint contains one slide and embeds its visual assets; it has no
external file links. Export it with Microsoft PowerPoint when revising the
figure. LibreOffice preserves the editable objects but does not faithfully
render the perspective transforms in panel a, so the supplied PDF is the
canonical appearance for comparison and publication.
